# Modernization Report — MI Digital Twin Management Platform (secsim)

**Audited:** 2026-08-26 · **Commit:** `d24f7f1` · **Branch:** `main`
**Stack:** TypeScript monorepo — React 18 / Vite 6 client, Express 4 / Mongoose 8 server, Node ≥20 engines, npm workspaces; dual GitHub Actions + GitLab CI with cosign/gitleaks/semgrep security pipeline
**Size:** ~129 source files (~63 ts server, ~60 tsx/ts client), ~20.3 kLOC under `server/src` + `client/src`
**Baseline:** AMBER — builds clean and typechecks; test suite runs but 5 of 8 files fail at import without an exported `JWT_SECRET`

## Summary

| Severity | Count |
| -------- | ----- |
| Critical | 4     |
| High     | 19    |
| Medium   | 77    |
| Low      | 38    |

This is an actively developed repo (81 commits in 12 months) with unusually strong CI hygiene for its size — artifact signing, gitleaks, SAST, and a real dependency-audit gate already exist. Its weaknesses are concentrated in three places: **secrets handling** (a committed default admin password and encryption key that seed themselves into production, plus cluster-credential ciphertext leaking through `.lean()` responses), a **test suite that is red everywhere except CI** because env parsing calls `process.exit(1)` at import time, and a **wide dependency currency debt** (React 18→19, Vite 6→8, Express 4→5, Mongoose 8→9, TypeScript 5→7, Tailwind 3→4, plus an EOL Alpine image and a known-compromised-history CI action pinned to a mutable tag). The plan closes the secrets and test-bootstrapping holes first, ships the security-driven upgrade wave, then modernizes majors one task at a time against a restored baseline.

**Top 5 by impact:** `F-BUG-002` — infrastructure credential ciphertext returned by public API routes → `F-BUG-001`/`F-BUG-003` — committed default admin password + encryption key auto-seeded into deployments → `F-BUG-008` — suite unrunnable locally (`process.exit(1)` at import) → `F-DEP-401` — tj-actions/changed-files on mutable tag with compromise history → `F-DEP-103` — react-router CVEs fixable only via the v7 major.

One helper eliminates a defect class. (`F-CLEAN-005`, `F-BUG-015`)

- **Committed/default secret values flowing into deployments** — env defaults + auto-seed + no-auth Mongo chain into production-guessable credentials. (`F-BUG-001`, `F-BUG-003`, `F-SEC-001`, `F-SEC-002`)
- **Import-time side effects poison testability** — env parsing exits the process at import; every suite importing routes/logger inherits it; docs quick-start inherits it too. (`F-BUG-008`, `F-DOCS-001`)
- **Serialized remote-I/O loops (K8s API)** — sequential awaited cluster calls on hot paths, re-run per polling viewer. (`F-PERF-003`, `F-PERF-004`)
- **Whole-document responses where projections suffice** — scenario lists, 1000-service dropdown fetches, unpaginated collections. (`F-PERF-002`, `F-PERF-006`, `F-BUG-002` amplification)
- **Mutable CI references** — every GitHub action and the GitLab component on movable tags/semver refs; one with compromise history; outputs shell-interpolated unescaped. (`F-DEP-401`…`F-DEP-408`, `F-CI-003`)
- **Docs generated from an earlier code shape** — Bun-era backend doc, phantom hooks/ dir, missing modules, dead commands; triple-sourced env documentation drifting three ways. (`F-DOCS-006`, `F-DOCS-011`, `F-DOCS-007`, `F-DOCS-009`)
